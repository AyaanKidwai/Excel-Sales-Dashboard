# Excel Interactive Sales Dashboard

An interactive Excel dashboard built to analyze sales data and highlight key business trends.

## Project Overview
This project focuses on transforming raw sales data into a structured and interactive dashboard for analysis and reporting.

## Work Done
- Cleaned and organized raw sales data
- Created Pivot Tables and Pivot Charts for analysis
- Designed an interactive dashboard using slicers
- Analyzed trends by sales, region, customer segment, and channel

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning & Analysis

## Key Insights
- Identified monthly sales trends
- Compared performance across regions
- Analyzed customer segments and sales channels

## How to Open
1. Download the Excel file from the repository
2. Open it using Microsoft Excel (2016 or later)
3. Use slicers to interact with the dashboard visuals
