# Excel Interactive Sales Dashboard

This project showcases an interactive Excel dashboard built to analyze sales data and key business metrics.

## Project Overview
- Cleaned and structured raw sales data for analysis
- Created Pivot Tables and Pivot Charts to identify trends
- Added slicers for dynamic filtering across multiple dimensions
- Designed a user-friendly dashboard for quick insights

## Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers
- Data Cleaning & Analysis

## Key Insights
- Identified monthly sales trends
- Analyzed performance by region, customer segment, and channel
